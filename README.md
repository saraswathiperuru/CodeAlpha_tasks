CodeAlpha URL Shortener

About the Project

This is a URL Shortener web application developed using Python and Flask as part of my CodeAlpha Backend Development Internship.

It converts long URLs into shorter links that redirect users to the original website.

Features

- Shorten long URLs.
- Generate unique short codes.
- Store URL mappings using SQLite.
- Redirect short URLs to their original destinations.
- Display recently shortened URLs.

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

How to Run the Project

1. Clone or download this repository.

2. Install the required packages:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "python app.py"

4. Open your browser and visit:
   
   "http://127.0.0.1:5000"
